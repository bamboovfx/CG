# 领域文档读取规则

本项目采用 single-context，根目录为 `Shot_Test`。Drop临摹与原创镜头共用一份领域词汇。开始制作任务时读根目录 `CONTEXT.md`，只读取与本次工作有关的 `docs/adr/` 决策；缺少 ADR 时直接继续，真实决策产生后再创建。当前没有多包工程信号，不设 `CONTEXT-MAP.md` 或按镜头拆分上下文。

术语表只解释领域概念，不存参数、状态或实施计划。任务和评审沿用其中用语。实际工程与文档冲突时，先查当前文件与用户最新要求，再记录核实结果。

只有难以逆转、缺少背景会令人困惑且存在真实取舍的决定才写 ADR。普通材质参数、一次候选失败或任务完成记录放在任务卡和评审，不堆入 ADR。

输出与已有 ADR 冲突时，引用该 ADR 并说明重开原因；术语有实际缺口时交由 domain-modeling 维护，沿用已有定义。
