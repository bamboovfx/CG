# Triage labels

保留 skill 默认词汇；用户于2026-09-20随 PM 方案确认，并于2026-09-27明确要求“保留标签”。五个角色与标签同名，现有卡片沿用。

| 标签 | 含义 |
|---|---|
| needs-triage | 新请求尚未判断范围和优先级 |
| needs-info | 缺少必须的事实或用户决定 |
| ready-for-agent | 信息足够，可由代理完成 |
| ready-for-human | 需要用户进行审阅或操作 |
| wontfix | 已明确不执行，必须记录原因 |

任务生命周期看卡片 `State`；以上标签不表达完成度。视觉评审卡使用 ready-for-human，不能因此阻断独立技术调查。
