# ADR 001：当前教室镜头以本地工程作为外观编辑权威

日期：2026-09-29。状态：采用。

## 背景

旧镜头从建筑源和道具发布库跨文件链接。黑板等材质在镜头最终光照下无法直接修改；道具制作源和发布库又是独立副本，造成“改了源却不影响镜头”的误判。受控对照中，本地化但保留集合实例并未增加原始几何；约27.14秒与26.77秒的两次样本渲染不能证明稳定的性能差距。

## 决定

当前教室的建筑、道具与材质进入固定镜头工程，本地材质为当前画面权威。重复资产仍用集合实例和共享网格；黑板书写面可直接选中，其余实例材质由镜头内选择入口定位。旧资产文件保留为制作来源和恢复资料，不再视作自动同步的上游。

同一教室后续制作镜头默认共用材质。相机、World 和动画按镜头独立；必要的外观例外明确复制对象/网格/材质，并验证没有修改共用材质。第二镜头尚未正式建立，具体镜头编号和场景仍由各自规格决定。

## 代价与保护

固定镜头文件从本次迁移前约4.25 MiB 增至约66 MiB，单文件打开/保存代价更高；数据仍是实例化的。迁移前源、候选和同帧渲染对照保留。每次发布前比对正式文件哈希并重开验证；旧源改动不能直接覆盖本地镜头。

实施与操作证据见[迁移记录](../../06_review/classroom_pipeline_migration_20260929/report.md)。
