# 编辑替换后的教室课椅

本页记录前版逐椅独立网格／材质方案，已被2026-10-01用户要求的共享集合实例方式替代。当前操作入口请看[编辑共享实例课椅](edit_instanced_chairs.md)。

当前工作文件：`03_shots/sq010/sh010/work/drop_sq010_sh010_shot.blend`。用户2026-10-01通过整椅工艺／表现工作流后，授权替换原场景25把椅子。

原25个 `asset_desk_set_*_chair` Empty继续控制整椅摆位。其下为29个实际分件，归入 `prp_desks` 下的 `CHAIR NN / Editable parts` 集合；可以直接选中、进入编辑模式或修改材质。每件网格独立，每把椅子的根材质独立。通过的原资产位于 `02_assets/work/school_chair.blend`；现场检查与发布入口见 `06_review/chair_scene_replace_20261001/report.md`。

选中原椅子Empty，在“对象属性→自定义属性”调整：

| 属性 | 作用 |
|---|---|
| `Seed Wood` | 座面、靠背的老化／磨损／划痕采样，背板再加1 |
| `Seed Dirt` | 座面、靠背表面脏渍采样，背板再加1 |
| `Seed Metal` | 涂漆金属的掉漆／锈蚀／老化／划痕／脏渍内容 |
| `Seed Feet` | 四个胶脚的老化／擦伤／划痕／灰污内容 |

表现组公开Int `Seed`，根材质通过驱动读取所属椅子的属性。每椅种子固定、互不相同，重开和逐帧渲染不会重新抽取随机数。调整原控制对象的位置与旋转时，纹理继续锁在各分件的本地坐标／原UV。

Seed改变Blender表现内容的确定性采样相位：木板与脏渍为UV±1.8%，金属与脚套为内容周期±7.5%。它不重新生成底层SD贴图，不移动工艺纹理或近地／焊接接触包络。Seed=0时相位偏移为0，回到通过的源材质采样。原生SD高精度内容共用；各椅表现强度另外有约±2.5%的稳定差异。

单椅外观微调：选中对应分件，修改其独立根材质里的Age、Wear、Scratches、Dirt、Rust等接口。修改共享工艺组或共享表现配方内部节点会影响所有使用者；需要某椅独特配方时，对该表现组创建单用户副本。模型分件本身已是单用户网格，不需要再拆集合实例。

新旧资产背面方向相反，导入装配使用Z旋转180°，并计入旧座面的局部偏置对齐中心；新脚套最低点归零后仍使用原Empty的地面高度及比例。原椅模板保留为未摆放的恢复数据，当前画面使用新分件。原场景相机、动作、灯光／世界与其它资产保持；评审用已有教室机位，种子对照使用临时三点光场景且不写回。
