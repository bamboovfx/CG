# 根据参考制作可编辑资产的流程

2026-10-01用户指定的制作方式。适用于本项目后续参考驱动物件。每个环节先解决本环节的问题，检查通过后再向后推进；已验证的成果优先复用。本文是制作约定，不代表每个工具输出天然通过验收。

## 1. 明确模型参考和材质参考

模型参考用来判断轮廓、尺寸、部件数量和制造连接。材质参考用来判断颜色、反射、工艺、磨损、污渍和使用历史；可以来自不同照片，但最终必须作用于同一合理结构。

制作前列出部件清单。课椅至少区分座板、靠背、钢管架、横撑、固定片、紧固件和四个胶脚。即便外形连在一起，只要材料或后续编辑需求不同，就检查能否独立选择和赋材质。

## 2. imagegen生成一致的多视图模型参考

基于模型参考生成前、左、后、右视图；统一比例、结构、部件数量、方向和光照，完整显示物体，使用简单背景。胶脚、板材厚度、接缝和螺钉等容易遗漏的部位须明确要求并放大复核。

逐图检查四条腿、四个脚套、横撑走向和板厚是否一致。多视图之间若出现变形、增删零件或方向混淆，先在图像环节修正，不把互相矛盾的图交给Tripo。按实际工具入口准备独立视图，不能把含多个物体的拼图误当作单张模型照片。

## 3. Tripo生成、智能拓扑、分件与UV

把已检查的视图交给Tripo。采用Smart Mesh／可用的智能拓扑模式，按用途选择四边形或三角形与合适面数。随后单独检查分件与UV，它们不是“智能拓扑成功”的自动结论。

Tripo多视图P系列官方文档明确前／左／后／右视图，支持四边形输出选项和UV展开设置：[多视图文档](https://developers.tripo3d.ai/en/docs/generation-multiview-to-model/p)。Studio与API的参数、权限和消费以实际入口为准，不用历史任务设置推断当前支持情况。

分件先核对部件清单：按材质边界／制造连接拆分，可用Tripo智能分件并检查结果，也可在Blender沿现有边界修复。[Tripo分件](https://www.tripo3d.ai/features/ai-model-segmentation)提供单独的分件和后续编辑流程。UV可用导出的UV或[Smart UV](https://www.tripo3d.ai/blog/smart-uv)，然后必须在DCC内检查实际文件是否存在有效UV。

模型检查包含轮廓、尺度、管件圆度、板厚、穿插、缺面和法线。分件检查包含每个材料区域能独立选择、对象／材质槽是否正确、分件接缝是否影响轮廓和反射。UV检查使用棋盘格，检查拉伸、意外重叠、接缝、岛间距、方向和纹理密度。自动拓扑或自动UV的完成提示不能代替这些检查。

## 4. 根据材质参考制作工艺层与表现层

先完成干净工艺：木材／清漆、钢基底／漆膜、胶脚等，分别确定Base Color、Roughness、Metallic、Normal／Height和AO。需要高低模烘焙时，先定低模、硬边和UV，再烘焙并检查投射。

imagegen可以生成底层工艺的颜色／纹理参考，但必须去除灯光、透视和阴影影响；生成颜色图不能直接等同于正确的粗糙度、法线或高度。SD负责可复用工艺与高精度内容，SP负责基于实际资产布置和调整表现，Blender负责材质接线与最终光照验证；按任务需要组合。

表现层分别建立老化、磨损、划痕、氧化／锈蚀和脏渍。每个事件使用一致的位置蒙版，分别控制颜色、粗糙度、金属性、微凹凸和涂层覆盖，不机械地给所有通道同样的变化。木材、漆膜、胶脚和锈为非金属，露出的钢基底才进入金属响应。完整旧漆与局部锈蚀的颜色比例以实物参考为准。

图像／图案内容、资产上的损伤位置与强度控制分开保存。保持工艺／表现独立，提供可归零或关闭的表现控制，以便定位问题和复用。

## 5. Blender同光验证并保存

校核色彩空间：颜色图使用sRGB，Roughness、Metallic、Normal、Height与AO使用Non-Color；法线经正确的Normal Map／Bump节点连接。模型UV或映射坐标必须与贴图对应。

使用工作室三点布光与透视机位，检查整体、近景和斜角高光；固定灯光／曝光做前后对照。同时检查部件移动后材质是否滑动，局部凹凸是否过强、颜色是否过于单一、背面和窄边是否异常。保存后重开核对材质槽、分件、UV、依赖与当前编辑保护，再交用户确认视觉效果。

## 逐环节返修与复用

| 发现的问题 | 优先修复的位置 | 修复后需要重做的下游内容 |
|---|---|---|
| 只有材质颜色、粗糙度或接线不对 | 当前材质／表现控制 | 同光验证；模型和UV继续复用 |
| 脚套与钢管粘成一件，但已有清楚边界 | 当前模型分件 | 材质槽和接缝检查；UV保留时复用现有贴图 |
| UV拉伸／岛布局不合理 | 当前UV环节 | 依赖旧UV的烘焙和贴图重投射／重导出；程序化纹理内容可复用并重新映射 |
| 圆管、接头、非流形或低模拓扑不合格 | 模型／智能拓扑或局部建模环节 | 被改区域的UV、法线／AO等网格烘焙和损伤映射重检 |
| 生成模型漏件、结构错误且局部修复成本不合理 | Tripo生成环节 | 保留合格多视图和材质配方，重生成后重检分件、UV及网格烘焙 |
| 多视图本身结构矛盾或看不到必要零件 | imagegen多视图／模型参考环节 | 修正参考，再重新生成受影响模型，重检其下游依赖 |

回退到真正出错的最早环节，修复完成后从那里向后推进。局部修复优先于整件重做；只重做失效的依赖。相同UV／相同面保留下来的贴图通常可直接复用；换了UV不能盲用旧图集。换了模型但材料类别不变，可复用工艺配方与纹理内容，但必须重新绑定坐标和资产特定损伤位置。
