# 编辑共享实例课椅

正式文件为 `03_shots/sq010/sh010/work/drop_sq010_sh010_shot.blend`。25把椅子保留原控制对象的摆位，共同实例化 `CHAIR / Shared editable asset` 集合。母资产包含完整29个网格分件与31个根材质；集合实例不会逐椅复制这些数据。

## 调整一把椅子的外观

在教室场景选中 `asset_desk_set_*_chair`，进入对象属性→自定义属性。种子固定，移动物体或跨帧不会重新随机。

| 参数 | 作用 |
|---|---|
| `Seed Wear` | 金属损伤的位置、长短、形状和覆盖分布 |
| `Seed Metal` | 高精度金属破边、锈蚀、细划痕等内容相位 |
| `Wear Variation` | 金属位置／形状变化强度，0恢复参考位置包络 |
| `Seed Grain` | 木纹工艺层的裁切、宽幅纹理尺度及轻微木色变化 |
| `Grain Variation` | 木纹工艺变化强度，0恢复原工艺采样和颜色 |
| `Seed Wood` | 木材老化、磨损、长划痕内容相位 |
| `Seed Dirt` | 木板表面细小脏渍内容相位 |
| `Seed Feet` | 四个胶脚的老化、擦伤、划痕、灰污内容相位 |

金属损伤通过种子驱动的4D域扭曲改变位置和形状，再结合独立高精度破边采样；颜色、金属性、粗糙度与凹凸使用同一损伤蒙版。木纹五个工艺通道使用相同的安全裁切坐标，没有翻转或旋转切线法线。座面与背板有独立偏置，避免同一把椅子两块板也完全相同。

共享材质使用默认 **Attribute** 节点，Type=`Instancer`，读取当前实例的自定义属性。直接编辑母资产时使用明确默认值。这里的Seed改变共享内容的采样和程序损伤，并不逐椅生成新的SD贴图。

## 编辑全部椅子的模型或共用材质

顶部Scene下拉切换到 `Chair_Asset_Edit`；完整母资产的29个分件可直接进入编辑模式，也可修改材质节点。使用材质预览并按Home框选整个资产。切回原教室场景即可看到全部25个实例同步更新。

## 只让一把椅子有独立模型

只需要独立外观时，直接调整该实例属性。需要独立几何时，复制母集合及所需对象，令这把椅子指向复制集合；只把要修改的网格创建单用户副本，其余分件继续共享。也可以对该椅子执行 **Object→Apply→Make Instances Real**，再将需要修改的网格／材质设为单用户。实体化后原实例属性传递关系需要重新绑定或把当前外观参数写入独立材质，因此批量场景默认保留集合实例。

概念对应：完整分件集合是pack资产，原椅子控制对象是摆放点及其变换，自定义属性是逐实例参数，共享材质是读取这些参数的统一着色器。实际采用Blender集合实例，编辑母资产与编辑单实例参数是两个操作入口。

技术依据：[Blender Attribute节点文档](https://docs.blender.org/manual/en/latest/render/shader_nodes/input/attribute.html)。本工程也用两实例真实发光渲染验证了Instancer属性与Int组接口传递，见 `06_review/chair_instances_20261001/attribute_probe.json`。
