# Editable equipment Substance materials

See ../../../06_review/equipment_rebuild/review.md for visual reference, input bindings and material intent.

Nine native SBS graphs, nine real sbscooker-compiled SBSARs. Seven procedural families are self-contained. The two wood graphs expose WoodColorScan / WoodRoughScan / WoodNormalScan; bind the existing CC0 Poly Haven plywood 4K maps listed in ../../textures/generated/equipment_sd/manifest.json. The manifest preserves exact sbscooker and sbsrender commands, including all image-input bindings, plus output hashes and physical mapping.

Do not replace these outputs by earlier authored/equipment_rebuild Pillow maps. Those maps belong to the superseded first pass.
