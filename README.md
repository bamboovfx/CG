# 初版CG镜头测试：Drop关键镜头 → 个人短片

项目分两阶段：先复刻《dro:p》的关键镜头，验证从场景到可播放合成的制作能力；再将经过验证的方法用于自己的短片镜头。关键镜头按技术代表性和原创需求选择，不要求逐镜复制原片全部内容。项目范围见 [project_brief](00_admin/project_brief.md)。
