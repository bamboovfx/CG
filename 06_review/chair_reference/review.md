## 这次改了什么

| 上一版问题 | 当前处理 |
| --- | --- |
| 前腿顶部露出管口，直管之间硬拼 | 左右各一根连续弯曲侧框，前后腿平滑过渡到座下 |
| 后框穿入座板 | 后框绕至座后，木板与管架留出空隙；下端封闭并补连接腹板 |
| 横撑直接插进腿管 | 横撑两端依据接收圆管计算鱼嘴裁口；焊脚沿交线铺设 |
| 座面近似方板 | 前宽后窄、31mm圆角、浅坐窝、前缘下翻；板厚12mm |
| 背板过于平直 | 横向包覆、上沿轻微弧形和腰部弧度；板厚11mm |
| 托片为零散方块 | 背面圆角长托片；座下有弯折半径的冲压托片、隔振垫与六角螺母 |
| 木色平淡、清漆反光均匀 | 提升扫描木纹对比；暖色清漆、局部粗糙度变化、薄层压边与小尺度崩口 |
| 黑色脚套与实物不符 | 改成旧象牙色成型脚套，保留2K微表面纹理 |
