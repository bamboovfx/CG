# 课桌锈蚀修正 · 2026-09-11

固定工作文件：`../../02_assets/work/school_desk.blend`。此轮处理铁锈拉伸、方块边界与真实腐蚀置换；资产视觉验收仍待用户确认。

旧边界来自沿长管展开的 2K UV 遮罩，4K 微表面无法补足其轮廓分辨率。当前使用局部米制三维锈蚀场，保留原 UV 给印字；锈斑重新分布，脚底、弯管和桌肚切边定位保留。腐蚀起伏由 Cycles 真实置换与细分实现，细观部分保留原 SD 4K 层。
