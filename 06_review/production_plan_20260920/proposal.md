## 建议启用的 Agent skills 配置

```markdown
## Agent skills
### Issue tracker
任务与规格放项目内 .scratch，一任务一文件；见 docs/agents/issue-tracker.md。
### Triage labels
使用 skill 的五个默认标签，任务生命周期另记 State；见 docs/agents/triage-labels.md。
### Domain docs
单一 CONTEXT.md 术语表；只在重大取舍时增 ADR；见 docs/agents/domain.md。
```

`issue-tracker.md` 的具体约定：规格放 `.scratch/<effort>/spec.md`；任务放 `issues/NN-title.md`；`Blocked by` 用文件链接；未解决前置不可认领；`State` 是 `backlog / ready / in-progress / review / blocked / done / cancelled`；`Status` 保留默认 triage 标签。所有卡片列出验收、证据、下一步、阻塞原因；完成只由验收证据决定。已知未通过项不得藏在备注里。

`triage-labels.md` 的默认五标签：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。标签只决定由谁处理及信息是否足够，不能把 `ready-for-agent` 当作已完成。

`domain.md` 的具体约定：开始任务读 `CONTEXT.md`，按领域读取相关 ADR；不存在 ADR 时直接工作。术语表不塞实现参数，制作参数归规格和当前状态。

## 怎么推进

- 当前只允许一条镜头处于主要制作中；独立拉片、资料核对可以并行。
- 每一轮先指出差距，再做能被画面检验的改动，输出对照并更新任务。下一轮读取卡片和证据继续。
- 用户决定构图/表演/气氛是否符合目标；代理负责制作、技术检查和清楚解释。具体分工仍待回复。
- 技术检查自动推进，视觉关口集中审阅。未提出硬截止日期前，只给依赖顺序和已测渲染成本，不编造交付日期。
- 每次指导只列当前一步：打开什么、改什么、看什么、什么算通过。不把全套教程一次性倒给用户。
