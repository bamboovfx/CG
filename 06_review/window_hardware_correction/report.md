## 修改范围

- 左侧外窗当前可见的六组月牙锁（`.039`–`.044`）统一修正。旧隐藏版本与其他窗组未批量重建。
- 圆管弯环替换成有真实壁厚的封闭半圆锁杯；底座、轴、拨柄、锁杯、扣座分件。底座改装在内轨交接窗梃侧面，轴向为世界Y。
- 底座23.3×66mm、安装孔距40mm；拨柄轮廓参考 HHJ-0895。所有材质继续引用当前用户的金属材质，未改材质节点。
- 十二处凸起方块拉手改为26×134mm金属薄边框、16×105mm真实凹槽。凹槽切入窗梃5.5mm，槽底金属位于表面下约4.8mm。
- 窗梃保留 Boolean → Bevel → Weighted Normal，切割体默认隐藏并跟随所属窗梃。锁杯为网格实体，保留倒角修改器。
- 对侧扣座与螺钉随外轨窗扇移动；内轨锁柄与锁杯绑定各自的旋转控制器。恢复了当前第四窗缺失的配对扣座。

## 操作

- `ctrl_window_left_04`：Y方向推拉，Y=0回到关闭位置；当前用户开度约−0.217078m保持。
- `ctrl_window_lock_02`：Y旋转0°为闭锁位置、180°为解锁位置。当前开窗对应的锁已设置180°。
- 先解锁，再移动窗扇；两种控制是独立的，没有添加驱动或关键帧动画。
- `CUT pull pocket …` 是布尔切割体，默认关闭视图和渲染显示。需要编辑槽形时可在Outliner打开其视图显示；修改后保持隐藏。
