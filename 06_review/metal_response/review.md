# 金属材质校准 · 2026-09-13

本轮针对课桌/椅子漆钢、窗锁和轨道、螺丝五金、锡罐折边、钟表压圈与讲台露钢区域。相机、桌椅位置、灯光、木材、墙面、纸张及原有腐蚀置换保留。

## 检查结论

- 部分裸铝和五金的 Metallic 图整张固定为 0.82、0.85；锡板一组为 0.96。它们并未真正表达局部涂层/氧化覆盖，只让整件混入了漫反射。
- 课桌原漆面粗糙度图中位数约 0.495，钢层约 0.323。旧氧化控制多为 0.93；对露钢与氧化之间的过渡重新划分，使完整锈斑不再残留金属反射，磨损边缘能达到露钢端点。
- 几组五金法线图很接近平面，单看 Strength=1 不能断定法线过强。新增浅加工纹和匹配的反射方向，没有全局加重法线。
- 原讲台露钢底色为线性约 0.12/0.13/0.125，金属端点不到 1；底层钢板 Metallic=0.82。这些值令本应反光的细边发暗。

## 本轮实际处理

| 部位 | 处理 |
|---|---|
| 桌椅完整油漆 | Metallic=0；原 4K 粗糙度重映射为 .28–.43；增加 18 μm、低强度橘皮扰动。 |
| 桌椅露钢、锈 | 同一磨损场控制颜色与金属度；完整露钢=1、漆与锈=0，钢粗糙度 .20–.32，保留原锈的 .71–.93 图及真实置换。 |
| 铝、五金、锡板 | 完整表面 Metallic=1；各材质采用不同线性反射底色、粗糙度与各向异性；保留原始 2K/4K 贴图并叠加 3 μm 加工纹。 |
| 紧固件 | 从缎面本体分出较亮的镀锌螺丝材质，避免所有零件同样粗糙。 |
| 讲台 | 露钢底色 .52/.54/.55，金属端点 1；移除横跨锈层的清漆响应，保留原签名腐蚀场、涂层厚度及凹坑。 |
| 曲线五金 | 曲线保持可编辑，用物体坐标处理微表面，不引用只存在于网格的加工 UV。 |

新增网格 UV `MetalMeters` 以米为单位，U 沿面内较长方向；原 UV 全部保留。曲线件使用物体坐标和各向同性响应。新增原生节点保留默认名称，说明放注释框。
