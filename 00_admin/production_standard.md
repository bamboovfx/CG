# 制作规范

适用于本项目的Drop关键镜头测试与后续原创短片镜头。阶段范围以 `project_brief.md` 为准。当前优先完成主教室全景；规格与逐任务验收见 `.scratch/sh010-test`。

## 工作原则

先把一条连续镜头从拉片做到可播放合成，再复用它验证过的流程推进其他镜头。每次精修都要说明它对主机位或相邻镜头的贡献。资产数量、分辨率、节点数量和渲染样本数不代表质量通过。

原片可见事实、制作推测和用户决定分开标注。参考研究按明确问题开展，先读已有资料；找到能支持决定的证据后进入制作，不用无限收集拖延出片。

临摹以选定原片范围为画面依据；原创以用户确认的分镜、动作与美术目标为依据，单独建立镜头规格。当前Drop镜头的帧率、画幅和资产路径按其规格使用；原创镜头开始时再明确对应参数与源文件，不自动继承Drop的镜头时长或题材。

## 阶段关口

| 阶段 | 输入 | 可审阅交付与通过条件 |
|---|---|---|
| 拉片与规格 | 原片、用户目标 | 源帧边界、转场、动作节拍、首中末参考、制作帧映射；不确定性单列 |
| Blocking | 已锁定时基与动作范围 | 全长低成本视频；按镜头规格检查主体显露、相机运动与遮挡，涉及行走时再检查步态接触；用户通过方向 |
| Lookdev | 通过的构图与动作 | 主机位首中末样帧＋必要近景；材质工艺、尺度、冷暖、反射和老化合理 |
| Animation/FX | 通过的 Blocking | 全长表演、脚底接触、可见罐体/家具碰撞检查；布料/刚体需求明确，缓存可重开 |
| Lighting/Comp | 通过的表演与材质 | 全长渲染及合成；没有贴图丢失、闪烁、跳帧、剪切或重复调色；与原片并列检查 |
| Publish | 上述阶段证据 | 工作工程重开成功、依赖可解析、母版序列和视频完整、发布元数据与已知问题；用户通过成片 |

单个任务交付完整可验证结果，例如“有正确视差和遮挡的全长相机揭示视频”，不以“建完控制器”代替。阶段可以迭代；跨过关口的返工必须指出原因和受影响镜头。

## 技术与画面

- 单位米，Z-up；主教室正面 +Y，外窗 -X。原片已实测 24 fps，源帧零起始、Out 不含。当前镜头动态规格 24 fps、1001–1140（含）；候选中转换，发布前保护用户现存工程。
- 当前约 2.37:1 画幅；低成本动态测试可降分辨率，方向评审 1920×810，最终 2560×1080。播放器黑边不烘进母版。尺寸与样本写入每次评审，不能把低成本预览标成最终。
- 工作色彩沿用已保存 AgX 和色彩管理。EXR 存 scene-linear、视频使用一次显示变换，合成注明是否已应用显示变换；不二次套 AgX。
- 先以低样本首/中/末测出时间和噪声，再决定整段渲染设置。连续播放验收时间一致性；静帧干净不代表动画没有去噪闪烁。
- Base Color=sRGB；Roughness/Metallic/Normal/Height=Non-Color，OpenGL 法线。记录映射尺度。2K 是已用资产工作基线，不强迫每颗小螺丝独占一张纹理；按屏幕占比检查是否足够。
- 材质按工艺、使用行为和环境分层。黑板上中部擦拭、嵌灰、日晒与下部少用分别控制；不把实时窗影烘入 Base Color。参考厂商照片的许可不等于可直接做贴图。
- 窗帘使用真实 Cloth 求解。现有第120帧稳定形是静态资产；收拢预备动画不是镜头动作。是否加微风由镜头需要决定；使用时检查预滚、缓存、穿插与重复读回。
- 角色动作按具体镜头验证；需要步态的镜头先控制主体和脚底接触，再加有限二级运动。动态刚体只用于镜头需要的部分，不以全身自由掉落替代角色表演。

## 场景道具硬表面流程（2026-09-27用户要求）

- 窗户、五金、桌椅金属件和设备外壳等场景道具采用次世代硬表面流程：核实实物/尺寸/装配 → 可编辑高模 → 保轮廓的低模 → UV/密度/硬边 → 固定三角化 → 高低模烘焙 → PBR分层 → 棋盘格、中性光、镜头原光与运动检查。
- 结构按挤压型材、冲压薄板、铸件等制造方式区分；不以圆管曲线或实心方块代替缺少参考的锁片、扣座与凹入拉手。
- 主轮廓和承力零件保持可编辑；适合迭代的布尔切割体和倒角修改器保留，切割体隐藏并随所属部件移动。共享网格变更前确认使用者。
- 几何先通过真实尺度、厚度、硬边高光、孔槽和装配间隙检查，再叠加材质细节。机械开合要检查所属窗扇、转轴、解锁状态和滑动净空。
- 尺寸图能核实的尺寸直接标明来源；为本镜头适配的厚度与间隙明确注明，不能宣称完整工业复刻。本要求指导后续制作，不自动批量重建已通过的全部资产。

### UV、烘焙和材质交付（2026-09-28返工后补充）

- 可编辑高模与镜头低模分开保留；低模中的轮廓倒角在UV展开前定型。烘焙后不再随意改变三角化、法线或UV；修改后重新烘焙，避免切线基不一致。
- 接缝依据结构、硬边和遮挡布置，主要可见面保持整洁。先棋盘格查拉伸，再统一贴图密度与打包。必须检查最终求值网格，而非只检查倒角前的UV。记录塌陷、越界、重叠、密度、岛间距及检查精度。
- 重复件允许有意共享同一UV与网格；一次烘焙图集中不同模板不互相重叠。小零件共享图集，分辨率按近景屏幕占比决定，避免每颗螺丝各占4K。
- 高低模按零件匹配或爆炸排列，记录射线/笼子范围和padding。交付OpenGL切线法线与独立AO；检查投射漏点、接缝、凹槽和薄片背面。AO不默认乘入Base Color。
- PBR底色/粗糙度/金属度/法线的坐标系与尺度要明确。用于切线法线的贴图直接读取相应UV，不能用任意盒式投影代替。方向纹理与各向异性考虑零件制造方向，不能靠拉长噪声掩盖UV问题。
- 加工纹理先按物理尺度制作，再烘焙进UV。板材拉丝、铸件细哑光、涂层、接触抛光和环境老化分开推导；未经实物证据的工艺归属写成制作设定。
- 交付至少包含：可编辑高低模、实际使用低模与贴图、输入/输出哈希、同光前后对照、棋盘格近景、镜头读回。窗五金可复用实例见 [本轮记录](../06_review/window_hardware_pbr/report.md)。

## 文件与发布

- 现有目录职责保持；源文件固定路径见 `current_state.md`。源和发布库不是镜头版本。
- 所有实验写 cache 候选，元数据记录输入文件哈希、参数、脚本、帧段和输出。修改前保存恢复副本；发布前重新比对哈希，不覆盖审核期间用户新保存的内容。
- 当前教室的建筑、道具、材质在固定镜头工程内本地编辑，重复道具继续用集合实例和共享网格。旧建筑源、道具源与发布库保留为制作资料，不再是当前镜头的实时依赖；不要只改旧源却期待当前镜头自动刷新。
- 同一教室的新镜头在同一工程中共享常规材质，建立独立相机、世界和动画。镜头外观例外必须显式复制需变更的对象/网格/材质，标明适用镜头，验证共享外观未被误改。材质先在目标镜头灯光下预览，再出对应评审帧。
- 母版使用编号图像序列；视频仅为评审副本。发布包含起止帧、fps、尺寸、色彩处理、场景/缓存依赖与检查结果。工程可读回不等于视觉已经通过。
- 小迭代复用固定工作文件；只在 Blocking 锁定、样片通过、镜头完成等大阶段留里程碑。不要执行早期生成脚本覆盖用户手工编辑。

## PM 与指导节奏

任务卡是状态权威，看板是视图。每次会话选择已解锁任务，先写要解决的画面问题，完成后给证据、已知差距和下一步。按已选制作镜头跟踪交付；原片参考条目数不作为项目完成率的分母。

用户确认关键构图、表演和最终画面。代理提供具体可看版本、实施技术工作、解释判断。每次教学给一个可完成动作及判断标准；用户的时间安排明确后再填写日历计划。在此之前使用依赖顺序和实测耗时，不捏造截止日期。
