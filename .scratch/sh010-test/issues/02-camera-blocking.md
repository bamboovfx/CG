## What to build

## Acceptance criteria

- [x] 24fps、制作1001–1140，完整140帧视频可播放。
- [x] 前墙固定点位移、近景视差与人物首次可见时机有量化对照，误差明确。
- [x] 角色根部相对椅子固定；不加入未验证步态或相机roll。
- [x] 候选重开依赖完整，正式源文件哈希未改变。
- [ ] 用户通过相机/构图方向；未通过则保留差距返工。

## Capability evidence

13个身体段控制/167罐初次建立时保持世界矩阵，误差约4.8e−7。相机投影拟合后前墙159px位移基本匹配，近椅后半段仍约差18px。静态坐姿返工保持Root、环境及肢段长度，首帧过早露出的手脚已收回，末帧实际头部顶点误差约(−31,−5)px，脚接触代表点误差约(0.1,−0.1)px；这不代表人物轮廓或遮挡完全匹配。修正版140帧、24fps、5.833秒独立渲染与解码通过；源文件哈希未变，缺图0。旧版Workbench约126秒、三张32spp Cycles约55秒，是本轮本机实测，不能外推最终渲染成本。
