# 主教室全景 140 帧动态测试

Status: ready-for-agent
Spec approval: 用户在2026-09-20确认完整140帧动态镜头；具体艺术版本需阶段审阅。

## Problem Statement

立项时教室只有单帧效果，没有连续相机/角色动画；后续实况看任务卡与评审证据。用户希望用临摹检验模型与工具的实际制作能力，并积累个人短片方法，需要一条可播放、可编辑、可核对的完整测试。

## Solution

将原片主教室全景的140帧做成完整测试。先交付相机揭示人物的动态Blocking，再校准材质冷暖、局部表演和时间一致性，最后发布可重开的工程、母版序列和评审视频。

## User Stories

1. 作为创作者，我要知道准确参考起止帧，以免把多个机位误做成一镜。
2. 作为创作者，我要看完整时长的草案，以判断节奏而非只看静帧。
3. 作为创作者，我要人物与椅子的相对运动有画面依据，以免凭空增加步行。
4. 作为创作者，我要相机的近远景视差接近原片，以保留揭示人物的镜头作用。
5. 作为创作者，我要每次修改保留可编辑源和当前手工调整。
6. 作为创作者，我要暖教室、冷走廊的层次延续至动画，不靠全局滤镜遮盖错误照明。
7. 作为创作者，我要黑板工艺和使用痕迹在主机位下自然，不能因为近景细节多而抢主体。
8. 作为创作者，我要真实布料稳定形可重算，需动画时能解释预滚与缓存。
9. 作为创作者，我要没有漂浮、穿插、遮挡跳变和序列闪烁的播放结果。
10. 作为创作者，我要分清技术检查通过和我对画面通过的判断。
11. 作为能力测试者，我要保留失败、纠正和人工介入记录，避免夸大自动制作能力。
12. 作为学习者，我要每步明确操作和通过标准，以便复用到自己的短片。

## Implementation Decisions

- 参考入点00:02:39:07，出点00:02:45:03不含，24fps、140帧；制作1001–1140含。
- 以原片相机横向移动揭示人物为动作依据，固定人物根部与椅子关系。局部动作只做能验证的部分；不新增行走或把下一镜落座合并进来。
- 保留当前建筑、道具、真实Cloth稳定形及链接关系。候选验证后才更新固定工程。
- 渐进出图：低成本全长Blocking→主机位首中末lookdev→全长有材质测试→最终序列与合成。每步记录分辨率、样本、色彩处理和耗时。
- 输出画幅约2.37:1；阶段评审1920×810，最终2560×1080。低成本Blocking可降分辨率但需标记。
- 主要制作WIP=1。未确定的全片其他镜头不阻塞当前已锁定镜头。

## Testing Decisions

最高验收面是实际可播放镜头与原片并列对照。技术检查包括源文件保护、依赖重开、准确140帧/24fps、首尾和中间帧可读、缓存一致性及视频时长；连续播放检查闪烁与运动。对照固定背景和同排椅子判断相机/人物运动，不从单张截图猜表演。

视觉门槛由用户判断；自动检查不能伪造“用户已通过”。低分辨率样片只证明流程和方向，不代表最终噪声/材质质量。

## Out of Scope

当前任务不制作相邻落座近景、不改写个人原创剧本、不把原片的无音轨视频标成完整声画母版、不无限扩建无可见贡献的其他教室。
