# 教室材质编辑管线迁移规格

目标：在固定镜头的最终灯光下编辑黑板、窗框等教室材质，免去跨文件链接造成的来回切换。同一教室后续镜头默认共用外观，个别镜头能独立调整。

范围：迁移 `sq010_sh010` 当前已保存工程；保留旧建筑源、道具源、发布库与布料源。当前只有一个正式场景，第二镜头的编号和画面由后续镜头规格决定，不建立空的正式镜头。

验收：保留当前第1076帧、24fps、1001–1100、相机/天空Action、场景可见实例和变换；黑板书写面可在镜头直接选中；实例材质有可定位的编辑入口；重开后可修改相应材质；同帧画面对照基本一致；临时第二场景证明共用材质和镜头例外不会误改相机或原材质；恢复副本及旧源完整。

本规格仅处理编辑管线。140帧动态镜头、角色贴图和最终画面分别按既有镜头任务验收。
